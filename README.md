# TaskFlow — Простой менеджер задач

Веб-приложение для управления личными задачами. Позволяет создавать, редактировать и удалять задачи, отмечать их выполнение.

## Технологический стек

| Слой | Технология |
| ---- | ---------- |
| Язык | Python 3.12 |
| Фреймворк | FastAPI |
| БД | SQLite |
| Облако | GitHub Actions (CI) |

## Результаты аудита потока (AS-IS)

**Lead Time (от идеи до деплоя):** ~6 дней

| Этап | Processing Time | Wait Time |
| ---- | --------------- | --------- |
| Разработка фичи | 4 ч | 1 день |
| Код-ревью | 1 ч | 2 дня |
| Тестирование | 30 мин | 1 день |
| Деплой (ручной) | 1 ч | 1 день |

**Главные узкие места:**

1. **Ожидание код-ревью** — 2 дня простоя из-за отсутствия регламента
2. **Ручной деплой** — нет автоматизации, высокий риск ошибок

## Стратегия ветвления

Используется **Trunk-based Development** — все изменения вливаются напрямую в `main` через короткоживущие ветки (не дольше 1-2 дней).

| Тип ветки | Паттерн | Назначение |
| --------- | ------- | ---------- |
| Основная | `main` | Всегда стабильна, защищена Branch Protection |
| Фича | `feature/<название>` | Новая функциональность, мёрж через PR |
| Фикс | `fix/<название>` | Исправление бага, мёрж через PR |

**Правила:**

- Прямые коммиты в `main` запрещены (Branch Protection Rule)
- Каждый PR проходит CI (GitHub Actions) перед мёржем
- Ревью обязательно хотя бы от одного участника
