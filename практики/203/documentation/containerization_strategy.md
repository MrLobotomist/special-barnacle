# Стратегия контейнеризации — TaskFlow

## Выбор базового образа

| Образ | Размер | Причина выбора |
| ----- | ------ | -------------- |
| `python:3.12-slim` | ~130 MB | Debian-based, совместим с `psycopg2-binary` (требует glibc); alpine не подходит из-за musl libc |
| `postgres:16-alpine` | ~80 MB | Официальный образ, alpine-вариант для минимального размера |
| `redis:7-alpine` | ~30 MB | Официальный, alpine-вариант |

`alpine` для Python-образа отклонён: `psycopg2-binary` бандлит нативные библиотеки под glibc, на musl libc (alpine) потребовалась бы компиляция из исходников с установкой `libpq-dev`.

## Multi-stage Build: сравнение размеров

| Вариант | Размер образа |
| ------- | ------------- |
| Без multi-stage (`python:3.12-slim` + все зависимости) | ~310 MB |
| С multi-stage (builder отброшен, runtime только) | ~175 MB |

Экономия ~43% за счёт того, что в финальный образ не попадают pip, wheel-кэш и инструменты сборки.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
| ---------- | ---------- | --------------------- |
| `DATABASE_URL` | Строка подключения к БД (SQLAlchemy DSN) | `sqlite:///tasks.db` |
| `REDIS_URL` | Строка подключения к Redis | `redis://localhost:6379` |
| `POSTGRES_DB` | Имя базы данных (PostgreSQL) | `taskflow` |
| `POSTGRES_USER` | Пользователь PostgreSQL | `postgres` |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL | задаётся через `.env` |

Пароли никогда не хранятся в образе — передаются через `docker-compose.yml` из `.env`-файла или секретов CI.

## Порядок слоёв в Dockerfile

Зависимости копируются и устанавливаются **до** копирования кода приложения. Это позволяет Docker переиспользовать кэш слоя с зависимостями при изменении только `app.py`, ускоряя пересборку в 5–10 раз.
